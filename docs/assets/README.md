# README 插画

两张插画由 ImageGen 实际生成，用于项目介绍，画面中的点与曲线均为装饰，不是计算结果或科学证据。原始 PNG 原样保存，未重绘或改动元数据。

- readme-hero.png：温暖的研究工作台；青绿色戴眼镜小鸟，笔记、抽象数据、几何模型、插画和完成报告。
- readme-journey.png：保持同一角色的三联插画，依次表现观察、实验和检查报告。

生成需求：横向约 2.5:1，奶油纸色、薄荷绿与少量珊瑚色，成熟而可亲的手绘质感，无文字、数字、商标或具体赛题元素。此处为需求摘要，不冒充逐字调用日志。

asset-review.json 记录实际查看后的图像哈希。扫描器只能确认审核记录与当前图片对应，不能替人看图；图片更新后需要重新查看和记录。该审核只能解除对应图片的二进制待审状态，不会绕过路径或凭据告警。
