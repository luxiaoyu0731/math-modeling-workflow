# 已知限制与排障

- **缺少 paper-plan.json**：先识别是新写作还是已有工程。已有 TeX 使用 existing_tex，不能把缺计划直接判成论文错误。
- **缺少字体或中文乱码**：运行 doctor，检查实际中文字体及 PDFium 提取；打开渲染 PDF 判断是否真缺字。提取失败不代表视觉必错，仍须修复检查链或记录限制。
- **Word/TeX 行距不同**：相同倍率不代表相同物理基线距；严格要求需同字体样张测量，不继承其他项目字号或页数。
- **构建变旧**：先看变化文件与影响范围；重建受影响产物。不要手改旧快照哈希来消除告警。
- **隔离构建找不到图片/子文件**：补全 native.inputs，核对构建命令相对根目录的位置。不要把本机绝对路径写回论文。
- **ZIP 显示 REVIEW_REQUIRED**：扫描器发现二进制或嵌套包，需要额外检查；自动扫描无法判断图片是否包含身份或题目。通用发布包应尽量只含文本源码和合成示例生成器。
- **公式转换失败**：仅支持文档适配器明确列出的 Markdown/公式子集；不能静默把公式删掉。复杂 TeX 工程使用已有工程模式。
- **ImageGen 不可用**：只保存图卡和待办；不要把提示词输出算作生成图片。定量图必须保留计算数据层。

当前提供 Windows/Linux CI 配置；未运行过的远端任务、客户端或异机环境必须注明未验证。机器审核不证明模型正确、文献真实或比赛成绩。
