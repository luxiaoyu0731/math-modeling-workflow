- 既有 TeX 模式与生成式模式共用原有 G7–G9 接口；无第二套状态机。

- 58 项测试通过，三个合成 PDF 样张实际构建并查看；新增代码与既有调用路径已复查。
- 公开范围仅通用源码、文档、提示词、技能和合成示例生成器；实际论文、题目、数值工作簿、论文生成图及私有审核报告未加入包；两张通用 README 宣传插画有独立查看和哈希记录。

## 发布操作仍需完成

正式提交时重新检查索引和最终 ZIP，核对 Git 作者/邮箱、提交消息及远程目标。Git 内容扫描不包含这些元数据。按既有用户授权提交/推送；GitHub 登录失效时恢复登录后再推送。首次 CI 完成后如实更新远端验证结果，不提前标记绿色。
