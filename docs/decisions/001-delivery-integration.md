# ADR 001 补齐可执行论文交付

状态：采用。

## 问题
原分享版具备阶段记录与提示词，但技能细则、安装和文档交付依赖助手临时实现，不足以让新使用者稳定复用。

## 决定
保留G0—G9、Meta-Prompt、证据失效和ImageGen流程。参考MathModel-Skill的章节合同、证据绑定、构建新鲜度和实际渲染机制，自行实现适配现有接口的内容与交付工具。只复用其独立的MIT公式转换模块，固定上游提交并保留许可。

新增可选python-docx、pypdf、lxml、latex2mathml以及外部LibreOffice/XeLaTeX适配；核心检查仍为标准库。用户已同意增强Word与LaTeX能力，不自动安装用户环境依赖。

## 边界与取舍
不移植固定页数、固定章节目录、自动多代理或整个上游状态机。篇幅与格式从计划读取。简化Markdown子集便于核验，复杂格式失败时需显式适配，不静默丢失。

## 验收
覆盖数值与来源不一致、文件变动、引用缺失、图形记录、原生公式、安装冲突、确定性包及真实双格式渲染。人工视觉记录只在实际检查后填写。保留未验证的科学质量边界。

## 兼容与回退
新运行使用v8并绑定实时论文验收；历史v7不自动迁移。变更仅在公开通用仓库中，原论文及个人技能库不变。回退可使用旧发布提交在新目录检出，不覆盖已有任务数据。
