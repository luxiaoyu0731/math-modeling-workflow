# ADR 002 既有工程与发布验收

状态：采用；用户要求补齐发布前评估全部项目，并采用所建议的 MIT 许可。

## 接受的行为

保留生成式接口，native 模式只适配既有 TeX 的声明输入和明确命令。统一由 paper.py 的 audit/build/render/verify 调用，原工作流 G7–G9 无需另建状态机。新审核字段可选以兼容旧项目；native 必须记录模型取舍与验证范围。

分区页数、逐页审核、变更影响各自绑定实际文件；任何声明均不自动升级为科学正确性或真实人工操作的证明。发布扫描只做文件与模式检查，二进制和嵌套材料保留人工检查状态。

## 复用与依赖

已检索 Gitleaks 主仓库（https://github.com/gitleaks/gitleaks），可用于额外凭据扫描，不引入为必装依赖，也不复制它的规则或 Actions 包。现有 Python 标准库足以完成声明清单、SHA-256、ZIP 和基本路径扫描。现有 XeLaTeX/LibreOffice 复用，无新增常驻服务。

## 回退与测试

变更范围限通用仓库；计划不自动迁移，原论文不变。测试覆盖缺文件、失败构建、陈旧记录、页数重叠/缺页、脱敏告警、篡改 ZIP、Git 索引与工作区区别、实际 TeX/Word 渲染。远端 CI 需真实推送后确认。
