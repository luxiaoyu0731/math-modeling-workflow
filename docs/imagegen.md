# ImageGen 图形工作流

## 1. 先定义图要解释什么

按结构、数据、模型、结果、验证五种用途发现信息缺口，不按数量凑图。写清读者问题、对象、连接、边界、精确标注、证据源与正文位置。风格来自当前任务和参考图，不预设某种学科画法。

## 2. 实际生成

将图卡转成明确提示词，指定布局、对象关系、标注位置、风格和不能出现的内容。调用当前可用的 ImageGen 工具，保留实际提示与输出。不要把工具包装函数输出的提示词当成图片已生成。

## 3. 精确内容处理

生成图中的文字、公式、方向和拓扑逐项检查，需要时以排版工具叠加精确文字。数值图使用实际数据生成的曲线、刻度及误差范围，ImageGen 的视觉说明层不得改写这些内容；无法保证时保持原始数据层。这是同一制图流程的真实性要求，不要求制作多个版本供比较。

## 4. 验收与修订

先查科学语义，再查视觉：对象是否齐全，连接是否成立，方向和符号是否一致；然后按最终显示尺寸检查清晰度、对齐、留白和图注。失败时针对缺陷修改，避免无目的重复生成。合格的 ImageGen 成图可直接进入论文。

## 5. 保存与交接

记录原始输出和最终文件的哈希、精确标注源、采用或淘汰原因。生成过程通常不能像确定性绘图一样复现相同像素，因此保存实际素材比只保存提示词更重要。工具不可用时交付图卡和待办状态，不假称已经调用成功。
