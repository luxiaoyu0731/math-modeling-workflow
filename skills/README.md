# 技能目录

以下为本仓库整理的可独立阅读的阶段技能，不是私人技能库镜像，也不捆绑外部插件。默认直接让助手读取所需 SKILL.md 即可。

- [math-modeling](math-modeling/SKILL.md)：组织完整数学建模到论文交付，或协调跨阶段任务；不用于一般闲聊。
- [math-modeling-problem-framing](math-modeling-problem-framing/SKILL.md)：把数学建模题面与附件转成问题合同、变量单位和需求映射。
- [math-modeling-evidence](math-modeling-evidence/SKILL.md)：审核建模数据、参数和引用来源，建立清洗及假设证据。
- [math-modeling-solver](math-modeling-solver/SKILL.md)：把已选建模路线落实为推导、可运行计算和结果记录。
- [math-modeling-experiments](math-modeling-experiments/SKILL.md)：针对建模主张设计基线、误差、敏感性和适用性检验。
- [math-modeling-figures](math-modeling-figures/SKILL.md)：使用 ImageGen 设计和生成数学建模论文图形，并核验标注、语义与数据真实性。
- [math-modeling-paper](math-modeling-paper/SKILL.md)：从经过验证的建模产物撰写完整论文或指定章节。
- [math-modeling-final-audit](math-modeling-final-audit/SKILL.md)：审查建模论文的数学证据、图文一致和实际交付文件。
- [math-modeling-retrospective](math-modeling-retrospective/SKILL.md)：交付后提炼可复用的建模方法、失败原因与改进经验。

完整工作流由 math-modeling 协调，局部任务只读相应技能。需要正式工具集时使用当前环境可用的 ImageGen、计算、文档和PDF能力；本仓库不会自动安装或授权这些服务。
