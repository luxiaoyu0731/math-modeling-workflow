# Meta-Prompt 工程

Meta-Prompt 是可恢复的任务说明层；skill 负责方法，状态机记录阶段，实际文件提供证据。三者不能互相替代。

## 任务字段

每次任务包含：目标与范围、当前阶段、可用输入、事实与假设、执行步骤、预期产物、验收条件、资源预算、停止条件及交接。使用 [任务模板](templates/meta_task.md)。

## 按阶段加载

- 启动：输入与规则审计，见 [kickoff](prompts/kickoff.md)。
- Part1：读题、数据、建模、求解和验证，见 [part1](prompts/part1.md)。先数据审计，再模型选择；结果通过检验后才能成为正式主张。
- 图形：用 A–E 用途分类规划，执行 ImageGen 调用与核验，见 [figures](prompts/figures.md)。
- Part2：把已验证的事实组织成完整论文，见 [part2](prompts/part2.md)。
- Part3：对真实成品进行逻辑、数值和版式审查，见 [part3](prompts/part3.md)。
- 交付后复盘：保存通用经验，不继承旧案例参数，见 [retrospective](prompts/retrospective.md)。

## 泛化边界

不预设题型、模型族、章节数、图数、字数、页数、语言、字号或行距。必要假设明确标注并验证；模型复杂度由问题和证据决定。统计检验只在适用时采用，有限实验不支持“全域最优”等强结论。

原始文档、聊天记录和具体案例不随本仓库分发。本适配说明不以提示词中的角色身份代替真实专业资质或科学证据。
