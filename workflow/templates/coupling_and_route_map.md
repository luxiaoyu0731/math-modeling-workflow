# 耦合与模型路线图模板

## 1. 依赖与耦合图

用 Mermaid 表示子问题、数据、共享变量、资源、约束和输出。边上写明耦合类型：共享决策、时间顺序、资源竞争、数据依赖、评价器依赖或仅条件输入。

```mermaid
flowchart LR
  R["题意需求 / requirement_id"] --> A["子问题与交付"]
  A --> V["共享变量与约束"]
  V --> M["候选模型路线"]
  M --> O["结果字段与验收"]
```

## 2. 路线筛选

| 路线 | 适用前提 | 能解释什么 | 复杂度/数据要求 | 未覆盖耦合 | 采用或拒绝理由 | 主张边界 |
|---|---|---|---|---|---|---|
| Route-A | | | | | | |
| Route-B | | | | | | |

至少保留两条候选路线。不能以“更复杂”作为采用理由；需要说明解释力、可识别性、可计算性、可验证性和交付匹配度。
