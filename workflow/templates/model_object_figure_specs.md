# 模型对象图规格模板

> G3 设计、G6 正式生成。这里要求的不是公式依赖流程图，而是让读者看见公式所描述的数学对象、边界、关系和变化。每项不适用时写 `not_applicable + 原因`；不能以纯装饰插图代替。

## 规格清单

| visual_id | 数学对象类型 | 读者需要理解的模型关系 | 必须画出的对象/边界/变量 | 视图、坐标或时间方向 | 对应 requirement_id / formula_id | 生成源与方式 | 明确不画什么 | 状态 |
|---|---|---|---|---|---|---|---|---|
| M-01 | `[几何空间 / 图网络 / 时间轴 / 队列 / 概率分布 / 矩阵 / 其他]` | | | | | ImageGen | | template |

## 选择规则

- **几何/空间/覆盖/可见性模型**：画坐标系、区域或曲面、边界、关键点/线段/射线、角度/距离、可行域和必要的投影或剖面；严格区分直线、射线、线段及参数域。
- **三角形、多边形、圆锥曲线或解析几何模型**：画构成公式的顶点、边、辅助线、角/长度、区域和约束边界；图中符号必须与公式一致。
- **网络、路径、分配或流模型**：画节点、边、有向性、容量/成本或资源关系；不要把算法迭代箭头伪装成实际系统因果。
- **时间序列、排队、调度或状态转移模型**：画时间轴、事件、窗口、状态、资源占用和先后约束；用甘特图或状态图解释指标为何这样聚合。
- **概率、统计、评价或矩阵模型**：画样本/特征/指标集合、比较关系、权重或变换前后对象；数据结论仍须由结果证据图支撑。

## 共同质量要求

- 对每个关键公式，说明图中的哪一对象、边界、变量或关系帮助解释该公式；不要求画“公式之间的依赖网络”。
- 图形由 ImageGen 生成后核对对象、方向、几何关系和符号；必要时叠加精确标注。非按比例的示意需注明，定量图形必须保持真实数据几何。
- 图只解释模型设定；除非来自最终评价器，不能声称数值效果、因果或最优性。
