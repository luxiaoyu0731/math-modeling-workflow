# 求解器证据计划模板

> 本模板不要求所有问题都使用同一种算法或强行增加算法；它要求结论强度与实际证据相称。任何“最优、收敛、算法优越、鲁棒”等词均须回填至 `claim_ladder.csv`。

## 1. 原问题与求解域

- 原变量、定义域、硬约束与目标：
- 是否降维、固定变量或分层：
- 若分层：任务分配/子问题契约、可行性继承条件、未探索耦合与结论边界：

## 2. 主求解器的可复现规格

- 算法名称与适用原因：
- 初始化/候选构造：
- 邻域、变异、交叉或局部算子：
- 接受与保留规则：
- 随机种子、重启数、候选/迭代/时间预算、停止条件、运行时间和返回状态：
- 搜索评价器与最终报告评价器；两者不同的转换与统一复算：
- 若使用二分、线搜索或事件端点定位：被求函数/谓词、初始括区、连续性或单调性依据、端点符号/残差、容差及不适用时的替代程序：
- 若零/空策略在局部邻域内恒为不可行或零收益：如何构造可行初值、重启或跳出算子；相应失败用例：

## 3. 对照与证据边界

- 给定策略或题设基线（同一最终评价器）：
- 可解释基线/消融基线（同一预算或明确不可比原因）：
- 独立算法、精确求解器或证书；若没有，写明原因并禁止算法优越/最优性主张：
- 对混合离散任务：至少一个透明的分配/分层基线或局部联合重优化：
- 输出：候选预算—目标记录、多种子分布、最好已评估值、可行下界/上界（若有）：

## 4. 分层验证对应关系

| 想主张什么 | 直接所需证据 | 不能代替它的证据 |
|---|---|---|
| 数值积分稳定 | 时间步或容差复算 | 多初解、真实数据 |
| 空间/样本策略稳定 | 加密评价器下复算并至少一次重优化 | 固定策略加密本身 |
| 搜索质量 | 多起点、预算曲线、可解释/独立对照 | 时间步收敛 |
| 算法优越/最优 | 独立可比算法、界或证书 | 随机零基线 |
| 真实有效性 | 校准、实测或有依据的外部验证 | 题设内模拟 |
