# Part2 论文适配

先锁定通过验证的结果、主张账本、图表与引用；以当前官方模板为依据。

每问写成：要回答什么 → 为什么选此模型 → 假设与变量 → 方程及关键推导 → 实际求解 → 数值与图表 → 对照/验证 → 直接回答和适用边界。结果必须来自文件，不从上一轮对话记忆补数值。核心公式说明实际含义，创新只写确有证据的具体贡献。

先主体后摘要。保留原 Part2 的叙事连贯和公式解释；取消固定摘要字数、15–25 张图表、固定页数与强制创新标签，按 contest_profile 的规则排版。每节经纠错和压缩两遍，复核符号、单位、公式、引用和有效数字。按当前规则设置 AI 使用说明；工作流日志不进入评委阅读的正文。

输出：论文源码、正文数字追踪、反向大纲、引用与主张对应、分析推导覆盖、AI 使用台账和仍缺材料。不能把初稿称为可提交成品。
