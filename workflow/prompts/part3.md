# Part3 终审适配

从实际源码、结果文件、当前规则和新编译 PDF 审核，不沿用旧验收 JSON 的结论。按四种视角检查：建模逻辑、数值一致、评委阅读、格式与交付。

逐项定位：所有小问是否明确回答；关键假设及边界是否说明；符号、目标和单位是否统一；摘要/结论/图表数字是否可复算；源码和工作簿是否与正文一致；引用是否真实；是否保留无证据的最优/鲁棒/显著等强词。

按所选中文模板选择可用编译器，核验交叉引用和实际全部页面。检查匿名、页数、目录、AI 声明、完整可运行代码、支撑材料和文件清单；具体标准从 contest_profile 读取。人工核验记录和 AI 详情中的实际采纳/修改/复核信息必须真实。

输出问题表：位置、问题、证据、影响、最小修复、优先级、回退 Gate；以及 build_semantic_audit、submission_manifest、human_review_record 和最终候选包。有关键缺陷不放行；改模型或结果先回退，不在润色阶段补造依据。提交动作单独等待明确授权。
