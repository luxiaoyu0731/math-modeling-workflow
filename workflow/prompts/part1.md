# Part1 建模适配

保留原 Part1 的问题分解、学科依据、简约性与可执行交付，按当前 Gate 限定范围：

- G1：提取对象、已知量、未知量、约束、每问输出、量纲和子问题依赖；区分事实与候选假设。建立问题分析和验收映射。
- G2：先检查数据语义、来源、缺失/异常、单位及泄漏；变换可复算；外部参数可追溯，不能确认时保留参数区间或 blocker。
- G3：提出可手算基线、主路线、备选；记录选择依据、失败触发与回退。定义域、目标、约束先行，推导写清前提、步骤、意义、边界及近似。分解需说明共享资源和遗漏耦合。规划模型对象图。
- G4：实现批准路线，记录环境、种子、预算、停止条件、求解状态、可行性、原始结果和复现命令。仅生成代码不能算已求解。
- G5：同口径复算基线及主方案；根据题型分别检验数值误差、抽样、搜索质量、参数变化与适用边界。保留失败与负结果，不用稳定性替代最优性证明。

输出必须满足当前 Gate 的 artifact id 和模板，而非一次输出七阶段的想象结果。阶段末回答：哪些数据、结果或验证尚缺，是否允许进入下一 Gate。不能强行指定对数/指数函数、系统反馈或统计检验。
